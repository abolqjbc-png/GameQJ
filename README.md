# GameQJ — ساختار ماژولار

اجرا: فقط فایل **gameqj.html** را باز کنید (پوشه‌ها باید کنار آن بمانند).

| پوشه / فایل | محتوا |
|---|---|
| `gameqj.html` | فایل اجرایی + بارگذار برنامه |
| `css/styles.css` | استایل‌ها و انیمیشن‌ها |
| `config/tailwind.config.js` | تنظیمات Tailwind |
| `src/modules.json` | **ترتیب بارگذاری** فایل‌ها (فایل جدید را اینجا ثبت کنید) |
| `src/core/` | منطق بدون UI: ثابت‌ها، احراز هویت، کاربران/سکه/آمار، لابی، پیام‌ها، صدا، آواتارها |
| `src/core/toast.js` + `src/components/ToastCenter.jsx` | نوتیف‌های سراسری بالای صفحه (`showToast` / `hideToast`) |
| `src/core/store.js` | کاتالوگ فروشگاه (استایل مهره‌ها، آواتارها)، خرید، استفاده و `useEquippedStyles` |
| `src/ui/pieces.jsx` | رندر مهره‌های شطرنج و منچ با استایل‌های فروشگاه |
| `src/pages/StorePage.jsx` | صفحه‌ی فروشگاه |
| `src/components/AvatarCarousel.jsx` | اسلایدر انتخاب آواتار در پروفایل (کشیدن، فلش، کیبورد) |
| `src/ui/icons.jsx` | آیکون‌های SVG |
| `src/components/` | AuthModal، آواتار/پروفایل بازیکن، ChatPanel، چت درون بازی |
| `src/pages/` | دوستان، فروشگاه، مرکز بازی‌ها، پروفایل |
| `src/games/` | منچ، شطرنج، لابی بازی |
| `src/App.jsx` / `src/main.jsx` | کامپوننت اصلی / نصب روی صفحه |
| `dist/gameqj.bundle.js` | بسته‌ی آماده‌ی برنامه برای اجرا از فایل یا سرور |
| `build.js` | ساخت دوباره‌ی bundle: `npm i typescript` سپس `node build.js` |

## دو روش اجرا
- **دوبل‌کلیک روی gameqj.html** (file://) و **سرور/هاست**: هر دو از `dist/gameqj.bundle.js` استفاده می‌کنند؛ React و Tailwind از CDN بارگذاری می‌شوند.

> بعد از ویرایش فایل‌های `src`، برای اجرا در هر دو حالت یک بار `node build.js` بزنید تا bundle به‌روز شود. اجرای موبایل به دسترسی شبکه برای بارگذاری React نیاز دارد.

## ظاهر تخته‌نرد
- حرکت مهره‌ها با مسیر قوسی، فرود نرم و جلوهٔ زدن حریف یا خروج به سینی نمایش داده می‌شود؛ حرکت ربات و حریف آنلاین نیز همین جلوه‌ها را دارد.
- در گوشی، سینی‌ها بالا و پایین تخته قرار می‌گیرند تا خانه‌ها و مهره‌ها بزرگ‌تر باشند. دکمهٔ «نمای بزرگ» فضای بیشتری به بازی می‌دهد و با همان دکمه یا Escape بسته می‌شود.
- جلوه‌ها از وضعیت بازی جدا هستند و با تغییر اندازهٔ صفحه یا خروج از بازی پاک می‌شوند. با فعال‌بودن تنظیم کاهش حرکت دستگاه، انیمیشن‌ها غیرفعال می‌شوند.

## تغییرات نسخه‌ی ارتقایافته‌ی منچ
- صفحه‌ی جدید: قاب چوبی، آشیانه‌های شیشه‌ای رنگی با لانه‌ی گرد، مسیر با خانه‌های برجسته، مسیر ورود رنگی، مرکز رنگی با تاس.
- مهره‌ی پیش‌فرض سه‌بعدی و براق؛ مهره‌های فروشگاه هم با انیمیشن‌های جدید کار می‌کنند.
- موقعیت همه‌ی مهره‌ها درصدیِ خانه‌ی ۱۱×۱۱ است؛ حرکت خانه‌به‌خانه و بدون خروج از کادر (جهش، درخشش مهره‌های قابل‌حرکت، درخشش آشیانه‌ی نوبت فعلی).
- مهره‌های رسیده به مقصد در ردیف «خانه‌های هدف» کنار آشیانه‌ی خود می‌نشینند (دایره‌های خط‌چین).
- تاس کنار چت حذف شد؛ فقط تاس مرکز صفحه مانده و چت بازی به بالای ستون کناری آمد. راهنمای نوبت زیر صفحه قرار گرفت.
- بعد از هر ویرایش در src اگر با دوبل‌کلیک اجرا می‌کنید: `node build.js`

### ویرایش دوم
- تاس هنگام پرتاب در سراسر صفحه می‌غلتد (دامنه‌ی پرش کم‌کم کم می‌شود) و بعد با حرکت فنری به مرکز برمی‌گردد؛ عدد نهایی همان لحظه‌ی برگشت نشان داده می‌شود.
- دایره‌ی نازک سفید دور مهره‌های پیش‌فرض برداشته شد.
- رنگ خانه‌های مسیر از سفید به خاکستریِ مایل به آبی (ملایم‌تر) تغییر کرد.

## انیمیشن شروع بازی (VS)
- `src/components/VsIntro.jsx`: نمایش حریف‌ها با پروفایل، نام و مهره‌های هرکس (شطرنج: ۲ نفر، منچ: ۴ نفر). با لمس رد می‌شود و در بازی مجدد دوباره نمایش داده می‌شود.
- کنار مهره‌ها صاحبشان نمایش داده می‌شود: منچ (پلاک آواتار و نام روی هر آشیانه) و شطرنج (نوار بازیکن بالا و پایین تخته).
- چرخش تاس با انیمیشن CSS نرم انجام می‌شود؛ دایره‌ی دور تاس و دایره‌های آشیانه/هدف حذف شد.

## جستجوی حریف آنلاین و خرید کیوجی
- `src/core/matchmaking.js` + `src/components/MatchmakingScreen.jsx`: «آنلاین» یعنی جستجوی حریف واقعی. ورودی ۲۵ کیوجی هنگام ورود به صف کم می‌شود و با لغو (یا بسته‌شدن تب) برمی‌گردد. شطرنج: ۲ نفر. منچ: با ۴ نفر فوری، با ۲–۳ نفر پس از ۱۲ ثانیه (جای خالی ربات).
- `src/pages/CoinShopPage.jsx`: صفحه‌ی خرید کیوجی (کلیک روی موجودی هدر). فعلاً بدون درگاه پرداخت؛ دکمه‌ی پرداخت فقط پیام «به‌زودی» نشان می‌دهد.
- تاس منچ: چرخش قدیمی (می‌آید روی تخته، می‌چرخد و سرجایش برمی‌گردد).

## واکنش‌های بازی (پرتاب آیتم روی پروفایل حریف)
- `src/core/reactions.js`: فهرست آیتم‌ها و قیمت‌ها (۳ تا ۸ کیوجی)، ارسال، ضد اسپم (۵ ثانیه بین دو پرتاب، سقف ۳۰ پرتاب در هر مسابقه)، صداها.
- `src/components/ReactionLayer.jsx`: پرواز و افکت‌ها روی یک لایه‌ی بدون کلیک؛ برای همه‌ی بازیکنان مسابقه نمایش داده می‌شود.
- `src/components/ReactionTray.jsx`: دکمه‌ی شناور 🥚 پایین-راست و منوی پرتاب (در شطرنج، منچ و دوز).
- هر آواتار/پلاک بازیکن با `data-gq-player="نام"` علامت‌گذاری شده است؛ برای بازی جدید فقط همین را اضافه کنید.
